# 使用教程

本文介绍如何用 AI 求职简历生成器完成「录入经历 → 针对目标岗位定制 → 导出」的完整流程。

## 准备工作

1. 启动应用（Windows 双击 `run.bat`，其他平台 `./run.sh` 或 `python3 -m backend.main`），浏览器打开 `http://127.0.0.1:8010`
2. 点击右上角「⚙️ 设置」，填入你的 API Key 与模型（详见 [README 配置模型](../README.md#-配置模型第一次使用)）

## 第一步：新建简历

左侧「📚 简历库」区域：

- 点 **＋ 新建**，创建一份简历（建议按目标岗位命名，如"投字节-后端"）
- 以后可以随时 **重命名 / 复制 / 删除**；点击列表项即可切换简历
- 每次编辑会自动保存（面板右上角显示"✓ 已保存"）

## 第二步：填写基本信息

- **姓名、电话、邮箱、城市、个人主页**：如实填写
- **求职意向 / 目标岗位**：填写目标岗位名称（如"Python 后端开发工程师"）

## 第三步：录入经历（两种方式）

### 方式 A：直接写要点

在「描述 / 成就」文本框里，每行一条要点，尽量量化：

```
- 负责订单系统重构，核心接口 QPS 从 2k 提升至 8k
- 主导微服务拆分，上线后故障率下降 40%
```

### 方式 B：STAR 引导（推荐给不会写的人）

1. 点击条目内的 **⭐ STAR 引导**，展开四格输入框
2. 按提示填写：**情境**（当时面临什么）/ **任务**（你负责什么）/ **行动**（你做了什么）/ **结果**（带来什么，尽量量化）
3. 点击 **✨ 整合为要点**，AI 自动把素材写成 3~5 条量化要点填入描述框
4. 不满意可以再点，或手动微调

## 第四步：JD 关键词分析

1. 把目标岗位的招聘描述粘贴到「目标 JD」输入框
2. 点 **🔍 AI 分析关键词**，等待结果：
   - **匹配度**：与目标岗位的契合百分比
   - **关键词**：JD 中值得在简历中体现的词
   - **修改建议**：针对这份 JD 的具体调整方向

## 第五步：AI 分步生成整篇

点顶栏 **✨ AI 一键生成整篇**，AI 按 5 步依次生成并自动填入：

1. 职业简介
2. 每条工作经历的要点
3. 每条项目经历的要点
4. 技能清单（结合 JD 补充）
5. 自我评价

生成过程实时流式显示。不满意的模块可以单独点 **✨ AI 润色** 重写。

## 第六步：AI 评分（可选）

点预览区工具栏的 **📊 AI 评分**，从招聘方视角给出：

- 总体分
- 四个维度分：内容完整性 / 量化程度 / JD 匹配 / 语言表达
- 💪 亮点、📈 改进建议

按建议迭代修改后可以再次评分。

## 第七步：导出

- **PDF**：点「🖨 打印 / PDF」，在打印对话框选择"另存为 PDF"（会自动隐藏表单，只打印简历）
- **Word / Markdown**：点「⬇ Word」或「⬇ Markdown」，文件同时保存到 `output/` 目录
- 导出前先在右侧切换模板（经典单栏 / 现代双栏）看效果

## 为下一个岗位定制

左侧点 **＋ 新建**，创建另一份简历，重复第二步到第七步。不同岗位的版本互不干扰，全部存在本地 `resumes/` 目录。

## 数据存在哪里

| 数据 | 位置 |
| --- | --- |
| 简历内容 | 项目根目录 `resumes/`（JSON 文件） |
| API Key / 模型配置 | 项目根目录 `config.json` |
| 导出的简历 | `output/` 目录 |

所有数据都在你本机，不会上传任何第三方服务。
